# VYRA Marketplace

واجهة VYRA الأولية لسوق الخدمات والمشاريع والمنتجات الرقمية والمحتوى القصير.

## التقنية
- Next.js 15
- React 19
- TypeScript
- CSS responsive مع دعم RTL

## التشغيل
```bash
npm install
npm run dev
```

## النشر على Render
- Runtime: Node
- Build: `npm install && npm run build`
- Start: `npm start`

> هذه نقطة انطلاق للواجهة الرئيسية. تسجيل الدخول، قاعدة البيانات، المدفوعات، الطلبات، لوحة الإدارة والـ API ستُربط في مراحل التطوير التالية. لا توجد مفاتيح سرية داخل الواجهة.
